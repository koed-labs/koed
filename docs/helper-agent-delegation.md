# Private Helper Agent delegation

Nova, Quinn, and Sage are User-owned Agents. On first local HQ setup, Koed creates any missing Helpers from the existing Chief of Staff's enabled AI Client instance, permission mode, and model choice. It keeps any Agent with an existing matching name and never replaces a User's customization. If the Chief has no valid enabled instance, Helper setup fails without choosing another provider or model.

In a private Project HQ Conversation, a leading exact mention such as `@Quinn fix lint errors` creates a child Managed Conversation for that owned Helper. This also works as the first message in an unstarted HQ: the existing Project HQ handle stays unstarted, and Koed launches only the Helper child. A later ordinary message starts Chief in that same HQ. A Team-linked Project can still have this private HQ path; it does not publish a Team Thread message. The visible task text becomes the child's first prompt. The child uses the Helper's configured AI Client, model, and permission mode through the existing local managed runtime. A missing or ambiguous Helper name fails before dispatch. Team Threads do not use this path; Agent mentions there remain outside this feature.

The Personal API requires local Project write and managed execution authority, derives the owner and runner device, and rechecks the active Project and captured Personal parent Conversation. Cold delegation locks the owner-qualified Project HQ handle instead; a new cold request conflicts if Chief has already started. The child start command and the owner-scoped parent or HQ handle, Agent, generation, and request mapping commit together. Retrying the same request ID with the same payload returns the same child, including after Chief later starts. Changing the Agent, task, parent, generation, or runtime selection conflicts. An uncertain delivery does not cause an automatic second launch. The renderer saves the draft and request ID for deliberate recovery.

Working now reads only owner-scoped delegation metadata: Agent ID, bounded task label, child execution state, and child session handle. It renders the Agent's Pixelkin from the existing Agent record. No child transcript, Team Thread message, or provider credential is published through this list. “Hire an agent” remains hidden.
