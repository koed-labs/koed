# How sharing works

Version 1. The Sharing page and Chief of Staff instructions import the text in `packages/shared/src/sharing-help.ts`. This file mirrors that wording for review. The IDs below refer to the committed acceptance contract and are checked by `apps/desktop/scripts/validate-hq725-help.mjs`.

## P1 · What sharing a Project shares

A shared Project gives its members its sources list, to-dos and Project memory. Each member's Project chats are shared as summaries according to that member's sharing setting, never as full transcripts. A full transcript needs separate consent. Eligible Project-scoped reviewed memories need group administrator opt-in, source-owner approval with an identity check, and supporting information from the exact shared chat. Me-scoped Personal Memory stays private. Source notes keep their separate grants. You choose whether each person can edit or only view.

Kept true by: I14.1, I713.12, N8.I.

## P2 · Some things stay private

Your Personal Memory and your private HQ Conversation with your Chief of Staff are not shared. After you make a chat private, anything you add stays private; its earlier shared summary stays in the Project.

Kept true by: S17.4, I713.06, N8.I.

## P3 · How memory works

Decisions and what agents learn in a Project go into that Project's memory for every agent in it. Your preferences stay in your own Personal Memory.

Kept true by: I713.12.

## P4 · Who keeps what

What people add to a Project, including chat summaries and documents, stays with the Project and its group if it has one. Removing someone stops their access and their agent's access, but does not delete what they added. Making a chat private or leaving stops future sharing; earlier shares stay. Shared memory still stops being used if its author asks Koed to forget it, when it expires, or if the Project owner removes it.

Kept true by: I720.1, I720.6, N11.I.

## P5 · When your agent shares

With Ask first, your Chief of Staff asks before inviting anyone. With Full access, it prepares the invitation for you; the required Native review still applies. Agent shares are flagged on Sharing and listed under Recently shared for 24 hours. There you can Remove access or Cancel invitation.

Kept true by: S723.2, I724.1, I724.2.
