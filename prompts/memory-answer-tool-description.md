Your user installed Koed so you can use captured AI Client conversations as memory. You SHOULD call memory_answer early, before planning or editing, for any substantive task where past work could affect current work. This includes most implementation, debugging, validation, configuration, design, and decision-making tasks. Prior successes, failures, errors, constraints, and decisions can prevent repeated mistakes and save work. When uncertain, call it; do not wait until stuck. Also use it for explicit recall, remembered user preferences, and user-provided facts. Skip it only for public facts, generic knowledge, trivial tasks, or work fully answered by visible material where history could not matter. Ask one focused question. If relevant knowledge lacks detail, call again with a narrower question; stop after a clear not-found answer. Default to search_domain=project; use search_domain=session for a known conversation and search_domain=global only for deliberate cross-project recall. Add time bounds only when requested. Default response_detail=answer_only; use with_citations for sources and with_evidence only for debugging/UI inspection.
