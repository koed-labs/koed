Recall captured AI Client conversations, remembered user preferences and user-provided facts before substantive work in a new chat or on a sufficiently new topic when prior knowledge could help. Ask a focused question; call again with a narrower question if useful; stop after a clear not-found answer. Default to search_domain=project; use search_domain=session for a known chat and search_domain=global only for cross-project recall. Team needs authorized Team Workspace scope and IDs from memory_workspaces. Use blocking if memory or finding none could change your next action; omitted/auto blocks. Use non_blocking when useful independent work exists: retain task_id, do that work, then collect with memory_answer_result when needed. Use wait_seconds=30 on collection if needed. Pending is not not-found: do not rapidly poll, repeat the request or act on memory before collection. No automatic wake. Follow-ups can use either mode. Request evidence only when the User needs it.
