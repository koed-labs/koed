Answer from Koed memory: captured AI Client conversations, saved sessions, project history, prior decisions, remembered user preferences, user-provided facts, setup/debugging work, and past discussions. Use for explicit recall and when prior work, attempts, constraints, outcomes, or decisions could materially improve the current task. Do not use for public facts, visible context, generic knowledge, or tasks fully answered by provided files or messages. Ask one concise question per topic. If relevant knowledge lacks a needed detail, call again with a narrower question for that fact, evidence, context, constraint, decision, outcome, or prior attempt; stop after a clear not-found answer. Default to search_domain=project; use search_domain=session for a known conversation and search_domain=global only for deliberate cross-project recall. Add time bounds only when requested. Default response_detail=answer_only; use with_citations for sources and with_evidence only for debugging/UI inspection.
