Recall captured AI Client conversations, remembered user preferences, and user-provided facts. Before substantive work in a new chat or on a sufficiently new topic, call memory_answer when prior knowledge could affect the task. Ask one focused question; call again with a narrower question if needed; stop after a clear not-found answer. Default to search_domain=project; use search_domain=session for a known conversation and search_domain=global only for cross-project recall. Team recall requires authorized Team Workspace scope: call memory_workspaces to discover IDs, then pass team_workspace_id and team_backend_id. Global without a Workspace searches Personal Memory only. Use global within a Workspace for Team-wide questions; project/session also filter shared source context. Add time bounds only when requested. Default to answer_only. Use with_citations for source attribution; use with_evidence or include_evidence=true only when the User requests evidence bodies.

Select delivery_mode from the next planned action. Request blocking for a direct recall answer, a decision or edit that needs prior constraints, or uncertain independence. Request non_blocking when useful independent work can precede the dependent action. A fix that needs prior memory can still start with independent diagnostic reads. Follow explicit User instructions to wait or continue independent work. Omitted and auto preserve the calling integration's configured default; they do not classify the query. Unsupported deferred contexts and configuration opt-outs retain blocking delivery. The AI Client assigned to Answer Synthesis does not select delivery.

After a pending receipt, do useful independent work and then yield before the first memory-dependent decision. In Codex, reach the native Stop boundary so its hook can await the result; in Pi, yield for the extension's follow-up. Claude may background the ordinary MCP call at the host level even when blocking was requested; await its result notification before a dependent action. Do not poll, run sleep tools or artificial work to keep the turn busy, repeat recall in blocking mode, invent remembered constraints, or claim the dependent task is complete. Apply the result before continuing the dependent work. On failure or uncertain acceptance, do not resubmit the request; report the unavailable prerequisite and leave dependent work unresolved. Successful not-found retains the no-repeat rule.
