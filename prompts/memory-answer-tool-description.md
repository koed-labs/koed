Recall captured AI Client conversations, remembered user preferences, user-provided facts, and other Personal Memory or relevant Team Memory. Before substantive work in a new chat or on a sufficiently new topic, call memory_answer before planning or editing to ask whether prior knowledge could affect the work. This normally includes implementation, debugging, validation, configuration, design, and decisions. Prior successes, failures, errors, and constraints can prevent repeated mistakes. Skip recall only when the task is simple and you are certain memory cannot materially help. Ask one focused question. If useful knowledge lacks detail, call again with a narrower question; stop after a clear not-found answer. Default to search_domain=project; use search_domain=session for a known conversation and search_domain=global only for deliberate cross-project recall. Team recall requires an available authorized Team Workspace scope. Add time bounds only when requested. Default response_detail=answer_only; use with_citations for sources and with_evidence only for debugging/UI inspection.
