Recall captured AI Client conversations, remembered user preferences, user-provided facts, and available Personal or Team Memory. Before substantive work in a new chat or on a sufficiently new topic, call memory_answer before planning or editing when prior knowledge could affect the work. This includes implementation, debugging, validation, configuration, design, and decisions. Skip only when the task is simple and memory certainly cannot help. Ask one focused question. If useful knowledge lacks detail, call again with a narrower question; stop after a clear not-found answer. Default to search_domain=project; use search_domain=session for a known conversation and search_domain=global only for deliberate cross-project recall. Team recall requires authorized Team Workspace scope. Add time bounds only when requested. Default to answer_only; use with_citations for sources and with_evidence only for debugging or UI inspection.
