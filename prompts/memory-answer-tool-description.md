Answer from Koed memory: captured AI Client conversations, project history, prior implementation, successful approaches, failed attempts, errors, constraints, decisions, remembered user preferences, and user-provided facts. Use for explicit recall. For an unfamiliar non-trivial task, call early, before planning or editing, when prior work could improve correctness, prevent repeated failure, or save work, even without an explicit request. Especially consider it when revisiting a project, debugging, extending earlier work, choosing an approach, or lacking task history. Do not use for public facts, visible context, generic knowledge, trivial tasks, or tasks fully answered by supplied material. Ask one focused question. If relevant knowledge lacks needed detail, call again with a narrower question; stop after a clear not-found answer. Default to search_domain=project; use search_domain=session for a known conversation and search_domain=global only for deliberate cross-project recall. Add time bounds only when requested. Default response_detail=answer_only; use with_citations for sources and with_evidence only for debugging/UI inspection.
