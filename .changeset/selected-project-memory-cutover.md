Use one selected repository anchor to group Projects and recall their Memory
across checkouts. Capture records repository assignments for Codex, Claude Code,
Pi, managed Conversations, and historical imports. Desktop supports individual
reassignment, bounded bulk review, and explicit shared anchor selection.
Create named local Projects from the Projects header or while moving a
Conversation. No folder is required. Move individual Conversations or entire
Projects from their headers. Whole-Project moves also route future captures
from that source into the destination. Empty Projects can receive unresolved
history.

Bind default recall to the Conversation folder across Codex, Claude Code, and
Pi, including when an MCP process starts in a different folder. Per-call context
keeps concurrent Conversations independent and preserves explicit Project targets.

Preserve assignments through Personal Device Sync and use separate Project
snapshots for Team Share Grants. Existing Sessions become unresolved once during
the upgrade. Explicit reassignment resolves them. Resetting that override restores
unresolved history. The upgrade preserves source Memory and retained provenance.

Global recall reserves a bounded candidate pool for the current repository and
uses a small relevance preference when context matches. Personal and Team
answers identify other Projects and preserve unknown provenance. Team matching
uses authorized Share Grant snapshots. No reranker service is required.
